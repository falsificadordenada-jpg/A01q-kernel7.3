# A01 (SM-A015M) panel: HLT "hlt_cd_jd9365d_720p_video"

Source: stock `dtbo` partition (9 overlays, LK applies index 8 on this unit; kernel cmdline
`mdss_mdp.panel=1:dsi:0:qcom,mdss_dsi_hlt_cd_jd9365d_720p_video:1:none:cfg:single_dsi`).
Controller: Jadard JD9365D. Mainline has `drivers/gpu/drm/panel/panel-jadard-jd9365da-h3.c`;
this panel needs its own entry (timings + init below).

## Mode
- 720x1520 @ 60 Hz, DSI video mode, burst, 4 lanes (lane_map_0123), RGB888 (bpp 24), sync pulse
- h: front porch 152, back porch 41, pulse 42 -> htotal 955
- v: front porch 18, back porch 12, pulse 4 -> vtotal 1554
- DSI PHY 12nm timings: 10 08 0d 04 00 07 04 0b, t-clk-post 0x13, t-clk-pre 0x24
- Backlight: PWM, 100 Hz, level 1..4095 (downstream `bl_ctrl_pwm`)
- Reset sequence (value, delay ms): (1,5) (0,5) (1,5)
- Supplies: vddio 1.8 V, bklight_en 1.8 V, lab 4.6-6.0 V, ibb 4.6-6.0 V (PMI632 LCDB; ibb post-on sleep 10 ms)
- ESD check: read reg 0x0a, downstream `panel-status-value` = 0x28
- Off: 0x28 then 50 ms, 0x10 then 100 ms
- On: init table below, then 0x11 (sleep out, 90 ms), 0x29 (display on, 20 ms), 0x35 (TE on)

## Other panels in the same dtbo (other A01 units may use them)
ili9881c, st7703, hx8394f (txd, gx, gx_cd), jd9365d (hlt, hlt_cd, hsd_jd9365da), ili9881c variants
(ls, ls_cd, hlt_mdt, hlt_hsd 80h/70h, jdd_hsd 70h), st7703 (gx, gx_hsd). The unit that selects each one
depends on the LCD id read by the bootloader.

## Touch / camera notes from the same dtbo
- Touch: `focaltech,ft5446` and `goodix,gt1x` both appear (units differ). Mainline edt-ft5x06 lacks ft5446.
- Cameras: 3 `qcom,camera` nodes (reg 0 rear mount 90, reg 1 mount 90 position 2, reg 2 front mount 270),
  plus eeprom x2 and one actuator. Sensor names are not in the dtbo (they are in userspace libraries).
